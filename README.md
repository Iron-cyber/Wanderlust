# 🌍 Wanderlust

A full-featured travel app that helps users explore destinations, view details, and manage their dream adventures.

## 🚀 Features

- 🗺️ Destination listing and details
- 🔍 Search & filter functionality
- ✏️ Add/edit/delete destinations (admin)
- 📦 RESTful routes using Express
- 🔐 MongoDB-based session and authentication
- 🧠 Clean MVC architecture

## 🛠️ Tech Stack

- **Frontend:** HTML, EJS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas
- **Templating Engine:** EJS
- **Middleware:** Express-session, connect-mongo
- **Version Control:** Git & GitHub
